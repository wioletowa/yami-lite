# yami-lite

Пиксельный шелл для [niri](https://github.com/YaLTeR/niri) в одном бинарнике: бар, док,
уведомления, всплывашки, виджеты, обои, блокировка экрана и настройки. Написан на Rust, рисует
сам (без GTK и Qt), шрифты Tiny5 и DotGothic16 вшиты внутрь.

Это личная облегчённая версия [yami](https://github.com/Trendorin/yami) 2.7.0: только шелл, без
установщика, обновлений и отдельных программ. Плюс своё — управление вентилятором ThinkPad,
цвета из обоев, сетка для виджетов.

## Возможности

**Бар** — сверху или снизу, полосой во всю ширину или плашкой с отступами. Модули раскладываются
по трём колонкам во вкладке «бар», у многих свой вид (шкала, график, число):

- столы niri (квадраты с номером или точки), окна стола, лаунчер (своя команда);
- трей: все значки в баре, закреплённые плюс стрелка, или всё под стрелкой;
- сеть и скорость, Bluetooth, раскладка, звук, батарея, ночной свет;
- cpu, ram, gpu, диск, температура, вентилятор;
- музыка, обои, Wallhaven, индикаторы микрофона, показа экрана и камеры;
- часы, уведомления, настройки, питание.

Модули ловят мышь на всю высоту бара, до самого края экрана. Правый щелчок по пустому месту
открывает панель управления.

**Всплывашки** по щелчку на модуль: календарь с историей уведомлений (щелчок по дню — «через
N дней»), звук (выходы, микрофон, громкость программ), музыка (обложка, перемотка, эквалайзер,
тексты песен), сеть с Wi-Fi, Bluetooth, система, батарея, вентилятор, Wallhaven.

**Панель управления** — часы на обоях, ползунки громкости и яркости, плитки: Wi-Fi, Bluetooth,
не беспокоить, ночной свет, микрофон, тема, звук, настройки, блокировка, питание.

**Уведомления** — карточки в любом углу, история, ответ прямо из карточки, картинки, «не
беспокоить», пауза таймера под курсором. Игровой режим: пока игра в фокусе, уведомления молча
уходят в историю.

**Док** — закреплённые и запущенные программы, умное скрытие, анимации.

**Виджеты рабочего стола** — часы, график (cpu, ram, температура, gpu), сеть, музыка, календарь.
Расстановка (`yami-lite msg edit`) показывает сетку 32 px и крест посередине экрана. Виджеты
примагничиваются к сетке, краям экрана, кресту, бару и друг к другу. С Shift — без магнитов.
Виджеты живут под окнами.

**Обои и цвет**
- своя картинка (с выбором из папки и затемнением) или пиксельные обои, нарисованные из палитры;
- плавная смена обоев пиксельным проявлением;
- пресеты палитры, свой цвет, светлая и тёмная тема, сохранённые темы;
- «палитра из обоев»: до пяти цветов картинки на выбор и второй акцент для графиков; тёмные обои
  тоже дают цвет, бесцветные — серую тему;
- перекраска программ: GTK 3/4, Qt, kitty, foot, alacritty, fuzzel, рамки niri.

**Ещё** — блокировка экрана (ext-session-lock, пароль через PAM), меню питания, OSD громкости,
яркости и Caps Lock, ночной свет через wlsunset, английский интерфейс.

## Чего здесь нет

Лаунчера, буфера обмена и скриншотов — это отдельные программы. Нет установщика, обновлений,
yami-files / view / play / greet. Шелл не пишет в конфиг niri: бинды и правила окон твои.

## Зависимости

Сборка: Rust 1.82 или новее (`cargo`).

| | зачем |
|---|---|
| **niri** | столы, окна, раскладка — через его IPC |
| **PipeWire** или PulseAudio, `pactl` | звук; `parec` — для эквалайзера |
| `playerctl` | музыка в баре и всплывашке |
| NetworkManager (`nmcli`) | Wi-Fi во всплывашке сети |
| BlueZ | Bluetooth |
| `curl` | обложки, тексты песен (lrclib.net), Wallhaven |
| `wlsunset` | ночной свет |
| `nvidia-smi` | датчики видеокарты NVIDIA (AMD читается из `/sys`) |
| `gsettings` | тёмная и светлая схема для GTK и Electron |

Всё, кроме niri, по желанию: нет программы — нет и того, что от неё зависит.

## Сборка и запуск

```sh
git clone https://github.com/wioletowa/yami-lite
cd yami-lite
cargo build --release
cp target/release/yami-lite ~/.local/bin/
```

В `~/.config/niri/config.kdl`:

```kdl
spawn-at-startup "yami-lite"

binds {
    Mod+S         { spawn "yami-lite" "msg" "settings"; }
    Mod+Escape    { spawn "yami-lite" "msg" "power"; }
    Mod+L         { spawn "yami-lite" "msg" "lock"; }
    Mod+B         { spawn "yami-lite" "msg" "bar"; }
    XF86AudioPlay { spawn "yami-lite" "msg" "media" "play-pause"; }
}
```

Настройки открываются обычным окном niri (app-id `yami-lite-settings`). Чтобы оно было
плавающим:

```kdl
window-rule {
    match app-id="^yami-lite-settings$"
    open-floating true
    default-column-width { fixed 900; }
    default-window-height { fixed 640; }
}
```

## Управление из терминала

```sh
yami-lite msg settings color     # настройки на вкладке «цвет»
yami-lite msg popup fan          # всплывашка бара
yami-lite msg edit               # расстановка виджетов
yami-lite palette sakura         # пресет палитры или свой цвет: '#3a9fd0'
yami-lite palette wallpaper      # палитра из обоев
yami-lite wallpaper ~/pic.png    # свои обои
yami-lite config set barPos bottom
yami-lite restart
```

Все команды: `yami-lite help` и `yami-lite help msg`.

## Настройки

Всё хранится в `~/.config/yami-lite/settings.json`. Файл появляется при первом изменении,
шелл перечитывает его сам — можно править руками или через `yami-lite config list | get | set |
reset`.

## Перекраска программ

Настройки → цвет → программы. Каждая выключена, пока её не включишь. Включённая получает файл
`yami-lite-colors.*` рядом со своим конфигом и одну строку подключения в нём (у niri —
`include "yami-lite-colors.kdl"` в конце `config.kdl`). Выключил — строка уходит, остальной конфиг
не трогается. Шелл меняет только цвета: темы значков и курсоров не ставит. У GTK вместе с
цветами переключается тёмная или светлая пара темы (`adw-gtk3` / `adw-gtk3-dark`), если она
установлена.

## Вентилятор ThinkPad

Модуль `fan` работает вместе с thfn-gtk (отдельная программа управления вентилятором) и не
заменяет её: кривую ведёт демон `thfn-gtk --daemon`, шелл говорит с ним через тот же
`~/.config/thfn-gtk/curve.conf`. На шкале во всплывашке:

- **C** — кривая демона;
- **A** — автоматика прошивки;
- **0–7** — уровень вручную;
- **F** — полные обороты.

Ручной уровень сначала выключает кривую, поэтому демон и шелл не спорят за вентилятор. Нужны
`thinkpad_acpi` с `fan_control=1` и права на запись в `/proc/acpi/ibm/fan`.
